01Why HackLab

つくって終わり、
にしない。
受託開発の、その先へ。

ハックラボは、2010年の創業以来、受託開発を事業の中心に据えてきた開発会社です。 Android黎明期からのモバイル開発、Javaを軸とした業務システム、そしてインフラ構築まで。 フロントエンドからバックエンド、インフラまでを一気通貫で担うことで、 チーム間の調整コストをなくし、プロダクトを最短距離で形にします。

いま私たちは、この16年の開発ノウハウに生成AIを掛け合わせています。 設計からテストまでAIを組み込んだ開発プロセスにより、短納期での開発や細かな仕様変更にも柔軟に対応。 そして、リリース後の運用負担まで見据えた設計で、10年以上大きなトラブルなく稼働し続けるシステムをお届けしています。

02Our Strengths

選ばれる、
6つの理由。

長年の開発経験と、先端の技術。その両方を持つチームだからできる受託開発があります。

01/ 06
  1. 01

    AI-Driven Development

    AI駆動開発

    設計からテストまで、開発のすべての工程に生成AIを組み込んでいます。人が判断すべきところに時間を使い、繰り返しの作業はAIに任せる。その分、短い納期でも品質を落とさず、途中の仕様変更にも落ち着いて対応できます。

    約4ヶ月→約1ヶ月まで短縮できたケースがあります（案件による）

  2. 02

    Mobile Applications

    モバイルアプリ開発

    Androidの黎明期からアプリを作り続け、入門書『10日でおぼえるAndroidアプリ開発入門教室』（翔泳社）も執筆しました。現在はFlutterを中心に、iOSとAndroidを一つのコードで開発しています。

    2012年、Androidの技術書を出版

  3. 03

    Full-Stack Delivery

    フルスタック一気通貫

    画面の設計からサーバー、データベース、クラウドやネットワークの構築まで、すべて自社のチームで担当します。窓口がひとつなので、会社間の調整に時間を取られず、何か起きたときの責任の所在も明確です。

    Front—Infraまで、ひとつのチームで

  4. 04

    Built to Keep Running

    運用まで見据えた設計

    つくる段階から、リリース後の運用を考えて設計します。監視と復旧の仕組みを自動化しておくことで、担当者の負担を減らし、長く安定して動き続けるシステムにしています。

    10年以上大きなトラブルなく稼働しているシステム

  5. 05

    Legacy Modernization

    レガシー刷新・コスト削減

    COBOLを含む既存のシステムを読み解いたうえで、無理のない形で新しい仕組みへ移行します。新しいiPadとの連携に数千万円規模のシステム更新が必要とされていた案件では、既存資産を活かした改修で年間数万円程度の運用に抑えました。

    数千万円の更新→年間数万円既存資産を活かして更新費用を回避した事例

  6. 06

    Education × Engineering

    教育 × 開発の知見

    2016年から子ども向けプログラミングスクール「8x9」を運営しています。教える現場で得た経験を活かし、マインクラフトのMod・プラグインや教材の開発を得意としています。

    2016年からスクールを運営

Capabilities

フロントエンドからインフラまで、
ひとつのチームで。

対応領域は6つ。どこか一部だけのご依頼にも対応します。

  1. 01

    Web Systems

    Webシステム開発

    業務管理・予約・受発注など、日々の仕事を支えるWebシステムを開発します。Java・PHP・Pythonなど、目的と既存環境に合わせて技術を選びます。

    Java / PHP / Python / React

  2. 02

    Mobile Apps

    モバイルアプリ開発

    Flutterを中心に、iOSとAndroidのアプリを一つのコードで開発します。SwiftやKotlinによるネイティブ開発にも対応します。

    Flutter / Swift / Kotlin

  3. 03

    AI Integration

    AIシステム開発

    生成AIを業務システムに組み込み、問い合わせ対応や文書作成などを自動化します。3年以上、AIと連携するシステムを開発してきました。

    生成AI / Python / API連携

  4. 04

    Cloud & Network

    インフラ・ネットワーク構築

    AWS・Azure・IBM Cloudでの基盤づくりから、ネットワークの構築、監視の自動化まで担当します。

    AWS / Azure / IBM Cloud

  5. 05

    Modernization

    レガシーシステム刷新

    COBOLなどで作られた既存システムを読み解き、業務を止めずに新しい仕組みへ移行します。運用コストの削減もあわせて提案します。

    COBOL / Java / 移行設計

  6. 06

    VR / AR / NFC / 3D

    先端デバイス・体験開発

    VR・AR・NFC・3Dを使った体験型のアプリケーションを開発します。AI関連の組織と、3D物体認識の共同研究にも取り組んでいます。

    VR / AR / NFC / 3D
