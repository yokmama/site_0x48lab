対応範囲

WordPress のバージョンアップ

本体・テーマ・プラグインを最新版へ。更新で動かなくなるプラグインは、代わりの選定や改修で対応します。

WordPress / テーマ / プラグイン

PHP のバージョンアップ

サポートが終了した PHP から、サポート中のバージョンへ移行します。非推奨になった書き方の修正まで行います。

PHP 7.x → 8.x / mod_php / php-fpm

データベースのバージョンアップ

MySQL・MariaDB などを新しいバージョンへ。バックアップを取り、データと文字コードの移行を確かめながら進めます。

MySQL / MariaDB / PostgreSQL

Laravel のバージョンアップ

メジャーバージョンを1つずつ上げ、Composer の依存パッケージとテストを確認しながら最新版へ移行します。

Laravel / Composer / PHPUnit

Node.js のバージョンアップ

サポート中の LTS 版へ更新し、npm の依存パッケージの更新とビルド・動作確認まで行います。

Node.js LTS / npm / ビルド環境

脆弱性への緊急対応

PHP の重大な脆弱性「PHP2Shell」など、急ぎの対応が必要なときもご相談ください。

PHP2Shell 対策 →

CLOUDFLARE

Cloudflare のドメイン設定・セキュリティ対策

ドメインを Cloudflare で管理すると、サイトの前に防御の層を置けます。設定を誤るとサイトやメールが止まるため、今の設定を確かめてから切り替えます。

ドメイン・DNS の設定

  • ネームサーバーの Cloudflare への切り替え
  • DNS レコードの移行と整理（Web・メール）
  • 切り替え中にサイトとメールが止まらないように確認

セキュリティの設定

  • SSL/TLS の設定（HTTPS の強制など）
  • WAF・ファイアウォールのルール
  • ボット対策と、ログイン画面などへのアクセス制限

FAQ

よくある質問

バージョンアップでサイトが壊れることはありませんか？

作業前にバックアップを取り、戻せる状態で進めます。可能な場合は本番と同じ構成の検証環境で先に試し、動かない箇所を直してから本番に反映します。

自社で作っていないシステムでも対応できますか？

はい。制作会社と連絡が取れないサイトや、引き継ぎ資料がないシステムも、ソースコードとサーバーを確認したうえで対応します。

Laravel を何世代も上げる必要があります。対応できますか？

はい。一度に飛ばさず、メジャーバージョンを1つずつ上げながら、依存パッケージとテストを確認して進めます。

Cloudflare の設定だけを依頼できますか？

はい。ドメインのネームサーバーの切り替え、DNS・SSL/TLS の設定、WAF やボット対策などのセキュリティ設定だけのご依頼にも対応します。
